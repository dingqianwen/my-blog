# 企业级可视化、拖拽式业务规则与决策平台（新项目发布）

原文：[微信公众号文章](https://mp.weixin.qq.com/s/Y2j4KUvB03cOix3QCHYWLw)

数海文舟重磅推出《可视化、拖拽式业务规则与决策平台》。该平台支持自定义函数、复杂参数、可视化公式配置、评分规则、判定规则、流程规则；支持多版本，提供快速对接文档、以及 SDK。

阿里云（`ecs.u1-c1m2.4xlarge`，总 16C32G 配置）下，计算服务与函数服务各分配上限 4C4G 双副本，压力测试 **> 5000/sec**（注：文档最后提供详细测试链接）。

## 规则引擎与大模型驱动的 AI Agent 区别

规则平台面向高频、实时、结果明确的业务决策，强调高性能、确定性和可追溯；AI Agent 面向需要理解、生成和推理的任务。比如优惠资格、计费、用户评分，应由明确规则执行；需求理解和营销文案生成，可以交给 AI。

| 对比 | 规则引擎 | 大模型驱动的 AI Agent |
|------|----------|----------------------|
| 性能 | 直接执行判断和计算，适合低延迟、高频调用 | 需要模型推理，多轮调用时延迟通常更高 |
| 确定性 | 同一规则版本、相同输入及依赖数据，结果一致 | 输出和执行路径可能变化 |
| 成本 | 部署轻量、运行成本低，单台 8 核 16GB 服务器即可支撑千级并发规则执行 | 模型推理开销通常更高 |
| 可解释性 | 能明确说明命中了哪条规则、为什么得出结果 | 推理说明不等于可验证的决策依据 |

## 规则参数

调用规则时的入参，类似接口定义约束的一些请求参数。支持普通数据类型传入（字符串、布尔、数值等）、对象方式、集合方式（集合支持嵌套对象）。

## 函数（系统函数、自定义函数）

函数主要是完成一些特殊场景的判断，例如查询数据库，调用第三方接口查询数据等。

### 系统函数

系统函数由平台内置，随函数服务启动自动同步。控制台可查看、模拟运行、查看引用，不可新建、编辑或删除。

## 评分规则

评分规则用来按路径累计数值分数。执行到计分板后写入本次分值，并继续后续节点；整次执行结束时，把命中的计分相加作为得分。未命中任何计分时，得分为 0。

**配置示例**

1. 已实名认证：加 20 分。
2. 近 30 天支付订单数不少于 3 笔：加 50 分。
3. 金牌（铂金、钻石）及以上会员：加 30 分。

## 判定规则

判定规则用来给出「命中哪个判定 / 未命中」。执行沿画布走到判定节点后写入命中并结束该路径；走不到任何判定则为未命中。

**配置示例**

1. 用户年满 18 岁并已实名认证。
2. 数据库中近 30 天支付订单数不少于 3 笔。

## 流程规则

流程规则用来按画布执行并返回一组字段。执行到数据输出后写入字段并结束该路径，不再执行后续节点。路径未走到任何数据输出时，结果为未输出。

**配置示例**

1. 高价值用户，输出可以领取优惠券，且优惠券为 `VIP_100`。
2. 非高价值用户，但是用户活跃度高，输出可以领取优惠券，优惠券为 `NORMAL_30`。
3. 其他场景，不发送优惠券。
